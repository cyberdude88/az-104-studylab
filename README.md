# AZ-104 Storage Drop Drill

A static, dependency-free study lab with two interactive drills in each of the five AZ-104 domains:

- Identity and governance: RBAC scope, policy, and locks
- Storage: resiliency and Azure Files with on-premises AD DS
- Compute: VM availability and scale sets
- Networking: NSG troubleshooting and VNet peering
- Monitoring and maintenance: metric alerts and VM backup

Drag an action into the answer table, or tap the action and then its destination. Correct placements turn green. Incorrect placements leave the card in the selection pane and show an explanation with Microsoft Learn references.

## Run locally

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Then open <http://127.0.0.1:4173>.
